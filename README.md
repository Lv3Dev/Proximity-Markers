# Proximity Markers
Highlights tiles around chosen NPCs, objects, graphics objects, and projectiles within a per-marker radius.

Add markers from the sidebar. Each marker can use an NPC or object ID or name, or a graphics object or projectile ID, and has its own colour, opacity, and Chebyshev radius that follows the target as it moves.

Turn on Explosion to add a death radius. Enter the NPC name to watch, then set a second proximity size and colour. That radius appears when the named NPC reaches 0 hitpoints and stays until it despawns. The original marker radius is unchanged.
